# Sign-Up Form — Spa Edition

A calm, editorial sign-up form for an imagined spa brand — built with HTML and CSS, with a focus on typography and layout.

## About

A two-column sign-up form with grouped fields, built with semantic HTML and CSS layout, with a warm, editorial feel inspired by minimalist spa and skincare branding.

## Design choices

**Typography**
- Headings: [Libre Caslon Text](https://fonts.google.com/specimen/Libre+Caslon+Text) — a classic serif for an elegant, editorial tone
- Body & labels: [Arsenal](https://fonts.google.com/specimen/Arsenal) — a humanist sans-serif for clean, readable UI text

**Layout**
- Two-column split: full-bleed still-life photography on the left, content on the right
- Form fields grouped in pairs (first/last name, email/phone, password/confirm)
- A raised white card (soft shadow) separates the form fields from the surrounding page copy

## Built with

- Semantic HTML5
- CSS3 (Flexbox for layout)
- Google Fonts (Libre Caslon Text, Arsenal)
